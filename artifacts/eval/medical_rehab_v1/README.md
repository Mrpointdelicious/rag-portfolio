## 实际失败与边界

- 开发 Q18：Dense Top-20 和融合候选并集都含 2 个必要来源组，Top-5 只覆盖 1 组；融合 Top-5 全部来自 D041。命中任一组不能算比较完成。
- 开发 Q20：Dense 候选已有 2 个必要组，Top-5 全部未命中指定范围。仅提高候选召回不足以解决最终证据选择。
- 开发 Q12：Dense 第 5 位命中跨语言范围证据，融合后丢失。开发 Q08 则由融合找回目的段；融合存在收益与退化。
- 测试 Q09：Dense 命中研究人群/结局证据，融合加入中文关键词相关的其他资料后未覆盖必需组。
- 测试 Q16：融合仅命中两组之一，Hit@5=1、完整覆盖=0，不能据此生成完整比较结论。
- Q02 的技术 Gold 固定在 D041 第 1 页，而 Dense 首位为第 2 页的分级说明。这提示备选 Gold 可能不足；本轮保留固定范围分数，后续独立复核，不据排名改本轮 Gold。
- D173 第 3 页复杂表格含异常字形，已排除检索与 Gold。解析失败页保留原 PDF 和提取日志。

显式条件的 Top-5 不匹配片段数：开发 Dense/BM25/Hybrid/Filtered Hybrid 为 4/16/8/0，测试为 4/14/8/0。过滤实现了结构化约束，但没有提高本轮整体命中率。这些计数只表示与题集条件不符，不能当成临床误用率；比较题未施加单病种条件时，不据其混合来源判断错误。

无输入题的 Dense 首位 cosine 区间：开发 6 题为 0.3711–0.7304，计分题为 0.4804–0.8695；测试 2 题为 0.5927–0.6432，计分题为 0.5731–0.8521。区间重叠，未设置生产拒答阈值。

程序源文件/页文本/字符范围校验全部通过，过滤后回填违规为 0。尚未全量人工核对 PDF 版面，也未评估生成回答、无证据编答、临床适用性或版本替代判断正确率；这些未测指标不能填 0。
