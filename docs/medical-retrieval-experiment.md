# 康复原始 PDF 独立检索实验

2026-10-10 在 `rag-portfolio` 落实第一阶段：备份全部盘点 PDF，准备 8 份首批语料，核对原文范围，运行医学独立 Dense/BM25/RRF 评测，并生成可追溯证据卡。旧元宇宙场景评测单独保留。

本次按用户要求，Word 文档不进入素材库。方案 DOCX 和盘点 XLSX 仅用于设计参考和来源清单；其中的候选状态、预计收益与未来任务不会自动变成已完成结果或审批。

## 来源与备份

盘点中的 180 份不同二进制 PDF 均已备份，覆盖 204 个来源副本/ZIP 成员。文件 SHA256 去重后，首批 8 份在 `doc/selected/`，其余 172 份在 `doc/unselected/`。后者包括其他康复候选、方法论文和其他领域文件，只承担备份。

备份程序逐个验证来源副本和目标文件 hash，保留原路径、ZIP 成员及可用 Zotero 标识。ZIP 只读取成员流，原文件与原压缩包不改动。已有备份不符时停止，不覆盖可疑文件；重复运行新增文件数为 0。

文件身份与作品身份分开。D041 与 D102 文件 hash 不同，去空白全文核查一致；两份都备份，只有 D041 进入本实验，不算两份独立证据。本轮没有完成所有 180 份文献的人工作品 ID、DOI 与版次家族确认，正式入库前仍需完成身份治理。

## 解析与证据定位

默认 pypdf，发现低文字量、异常字形等问题时尝试 PDFium；每页记录解析器与版本、尝试结果、原始文本/hash、规范化文本/hash和变换记录。只移除人工核对过且重复出现的出版页眉页脚，展开连字并修复已观察到的可见连字符；保留否定、数值和单位，不猜测跨栏阅读顺序。

D173 使用 PDFium，并对第 2 页的摘要与双栏进行视觉核对、按矩形分区提取。第 3 页表格仍有控制字形，隔离出检索语料及 Gold。其他来源均核对了首页文字/页码样本；没有声称全部 102 页都已人工排版验收。

块标识绑定文件 hash、解析器版本、页文本 hash、章节和字符起止范围。定位链为：证据卡 → chunk → 规范化页文本范围 → 原始 PDF 文件 hash 与 PDF 页。字符偏移不是 PDF 坐标，也不是原始抽取文本的偏移。

纸面页码独立记录已核对样本：D040 PDF 第 1 页对应期刊页 301，D001 第 1 页对应纸面页 8，D042 第 1 页对应纸面页 1。其余未确认纸面页保持未知。

证据卡显示标题、版次、发表年、PDF 页、章节、字符范围与原文片段，并链接到本地原 PDF。代码逐条校验来源映射；这种机器检查不替代对原 PDF 版面与临床内容的人工检查。

## 独立实验与评测口径

领域和实验强制使用 `medical_knowledge` / `medical_rehab_v1`。医学题集、Gold、路径、向量缓存、持久索引与报告都有独立命名空间。历史元宇宙实验的 12 个代码/题集/结果文件按启动前 hash 复核，内容未改动，指标不合并。

40 题先按原文明确必要证据组，再固定文本范围并映射 chunk。开发/测试为 28/12；Q21–Q28 缺少输入、Q40 文件身份核查不计入检索质量，实际计分为 21/10。测试先校验完整 dev 配置，再显式打开；本轮测试只运行一次，未据此修改排序、Gold 或参数。

四路对照为 Dense、BM25、RRF Hybrid 与医学条件过滤后的 Hybrid。Dense 使用真实模型调用，本地 Qdrant 持久化；BM25 使用完整固定语料的统计量；过滤在候选截断前执行。可用条件包括疾病、人群、病程、文献类型和版次，数组型病程支持成员匹配。条件由题集显式给出，是结构化过滤能力测试，未实现自然语言过滤条件抽取。

各路候选深度 20、最终深度 5、RRF 常数 60。完整保留候选 ID、Dense/BM25 分数及排名、融合排名，避免只看最终答案。单证据命中使用 Hit@1/5、MRR@5；必需证据覆盖为每题命中组比例的宏平均，完整覆盖要求全部组命中。“多篇证据”类别另报告，其他类别也可能含多个必要事实组。

Gold 是 Codex 的来源文字技术核对，尚无独立医学标注者或临床审批。它衡量已列原文范围的检索命中，不能直接解释为答案正确率；部分同样有效的替代段落可能未列全。下一版须在检索之前独立复核替代范围和问题资格，不根据本轮排名追补 Gold 后再宣称提升。

## 结果与后续边界

实际分数、调用量和失败案例见 [冻结结果记录](../artifacts/eval/medical_rehab_v1/README.md)。公共 `summary.json` 只含指标、指纹、来源 ID 与诊断计数，私有 `.local/` 保留全部原文证据卡和向量。PDF、来源本机路径及私有索引均不进入 Git/应用镜像。

本轮检索多篇证据完整覆盖不足、范围题失败、无答案分数与正例重叠，尚未达到接医学回答的质量条件。下一项围绕开发集 Q18/Q20 的候选已含必要组、Top-5 却丢失来源这一具体失败，先独立复核 Gold，再评估来源多样性或真实 reranker。保留当前模型/分块基线，不用已公开测试题调参。

下一阶段 retrieve/answer 需独立实施与验收：正式作品/版次身份、已批准内容、持久页码映射、tenant/KB/release 约束、完整发布/回滚与引用支持检查。实验快照不能直接成为活动 release。现有 `POST /v1/retrieve` 仍返回 501，未运行回答生成，也未把医学材料自动标为 approved。
