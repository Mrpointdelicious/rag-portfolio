# MetaAgent × 合并医学知识库 v2 迭代方案

日期：2026-10-12。状态：已按本方案实施，协议与范围保留在下文；实际结果见[实施与验证报告](medical-business-v2-results.md)。工程检查通过，业务验收PARTIAL，C不晋级；真实患者与既有生产均未接入或切换。依据：[v1业务基线](medical-business-v1-results.md)、[技术标注](../artifacts/medical-business-v1/technical_review.json)与当前MetaAgent源码。

## 目标与范围

下一轮优先改善MetaAgent对已取得证据的使用、失败原因表达和过期后的恢复。目标是：能查的问题先查；有依据的部分完成回答；不能完成的部分说明实际原因；旧证据失效后有限重新取证，仍失败则给出明确说明。

沿用14篇、713块、现有模型、Hybrid/Reranker及预算。原12道检索问题继续暂缓定点优化，保留于原50题回归。暂不扩大语料、调整分块/召回/重排、引入GraphRAG或额外Agent；真实患者远程知识路径及生产接入另行规划。

本轮证据更支持先改Agent与适配层。v1最终模型可见的必要锚点覆盖为开发17/22、保留10/15，但version-02没有查询便拒绝，过期追问因未重查而被现有引用保护拦截。这些任务失败不能靠提高召回率自动解决。精确锚点覆盖与语义正确性仍分别报告。

## 已确认的实现缺口

| 观察 | 源码核对 | 迭代含义 |
|---|---|---|
| 范围限制被说成未命中 | `HybridKnowledgeAdapter`对已验签的unavailable/failed结果保留部分code，但统一message为“未检索到演示资料证据”；trace未完整保留原因 | 优先修工具边界的状态投影，再验证最终中文说明，不只增加提示词 |
| 过期后未重查，最终回答为空 | `fresh_history`已有expired/query_hint，业务提示已有重新取证要求，发布前引用审计也已阻断失效来源 | 复用现有保护，补一次受预算约束的恢复，不能降低审计要求来让回答通过 |
| 书目问题未查便宣称无能力 | 当前能力视图只反映工具和配置允许的领域，没有清楚区分“允许查询”与“该发布实际装载的内容” | 补齐可信的发布能力说明；可查询的声明不能冒充已经取到的答案证据 |
| 真实医学库仍沿用合成资料说明 | `remote_hybrid.py`与`patient_views.py`含固定“合成技术文档”说明 | 按可信发布来源说明资料类型；保留原合成方案夹具的真实标签 |

## 工作包与优先级

### P0：先使任务完成与陈述支持可评审

冻结v2评分协议，补齐v1的评审缺口。先核查已有16条标注及相应回答中的额外陈述，再对45轮完整回答逐项标注；旧机器结果与Gold不覆盖，新增审阅文件引用原始run/answer hash。

新评测至少记录：用户要求的维度、可回答性及依据、实际完成的维度、每条关键陈述、支持它的有效且模型可见的原文区间、缺失原因及是否不当拒答。支持标签为支持/部分支持/无依据/矛盾/歧义/未评审。CG与COM这类术语替换保留待专业复核，不能因字符串不同直接判医学错误。

结构检查继续自动执行；语义标签由独立审阅者核对。独立审阅尚未落实时，工程开发可以继续，未审部分标为NOT_ASSESSED，整体业务验收保持PARTIAL。来源忠实性审阅也不等于临床应用批准。

### P1-A：让失败原因沿链路保真

在现有TaskResult/业务视图上增加最小状态投影，保留原始code、领域、是否实际查询、语料/索引pin、可见性限制及可恢复性。优先复用retrieval-v1；只信任通过既有校验的回包，HTTP错误仅按客户端可确认的错误类别解释。未知状态不能静默归为无命中。

| 已确认情况 | 用户可见含义 | 后续行为 |
|---|---|---|
| 工具未启用 | 本轮无法调用知识检索 | 不声称已经查过 |
| 领域不允许或发布未装载 | 当前知识范围未包含这部分资料 | 回答其他有依据部分，不建议盲目换词 |
| 正常查询确无命中 | 本次查询未取得相关证据 | 不升级为“该知识不存在” |
| 超时/连接或服务失败 | 本次未能完成检索 | 仅按现有总预算有限处理 |
| 权限、签名或来源完整性失败 | 当前不能使用该来源 | 不换域绕过，不按普通无命中重试 |
| 发布不可用或pin不匹配 | 当前配置的知识版本无法读取 | 不静默切库，不猜测具体撤销原因 |
| 原文已返回但上下文省略 | 当前可见内容不足以解释被省略部分 | 保留完整可见部分，说明预算限制 |

失败原因的事实句优先由程序按状态生成，模型负责连接有依据的内容。正文不暴露内部code，审计仍保留完整状态。混合问题按子任务说明，例如医学部分有依据、操作帮助未装载，不能把整题说成完全没有资料。

### P1-B：在原引用保护前补一次有限恢复

对能够确认属于历史知识证据过期的情况，保留受控恢复线索，复用现有`search_knowledge`、作用域检查、限流、超时和Evidence保存流程。旧正文与旧助手回答不能重新成为事实。

拟在发布前审计失败的明确过期场景中，最多执行一次恢复查询和一次重新生成，均计入现有调用/时间/上下文预算。只能使用原授权领域和当前有效pin；不是每轮强制查询，也不因有历史知识便对无关新问题自动补查。恢复仍失败或预算不足时，返回明确、非空的无法核实说明。

未知引用、篡改、跨作用域、权限或来源校验失败继续直接阻断，不纳入过期恢复。记录恢复触发原因、查询、调用数、返回的新证据、最终可见区间与最终审计结果；旧草稿不能提前发布。此机制只能处理可识别的过期路径，不能宣称自动识别所有无引用的旧答案复述。

### P2：能力认知、来源类型与部分回答

复用当前业务上下文，区分配置允许领域、发布实际装载领域与当前工具是否可执行。发布说明来自绑定pin的可信清单；查询后的来源类型由已验签回包核对。不以未认证health信息扩权，不把能力清单当作回答证据。若缺可信来源类型，则说明未知，不能默认称真实论文为合成资料。

书目和版本信息属于可查内容，但回答仍需检索原文并引用。比较问题按“人群、干预、计划结局、已报告结果、不可判断部分”逐项组织，只回答用户所问。计划指标不同可以比较设计，未报告效果时不能判断疗效，也不能把这一限制扩展成所有维度均无法比较。

优先用现有FactView与明确的任务维度组织回答，不新建通用复杂规划器。是否还需要调整证据打包，依据“已返回但不可见”的逐项轨迹另行决定；本轮先保持预算与算法不变。

## v2 EVAL设计

新增32个业务条件，8类各4个，16开发/16新保留。每类包含两个正向条件和两个限制/失败条件，分别分到开发与保留；多轮数量在编题时一并冻结，不能用条件数替代对话轮数。

| 类别 | 正向与限制对照 |
|---|---|
| 能力与书目信息 | 可查题名/版次需实际取证；工具禁用或所问来源缺失时不假装查过 |
| 服务原因与混合路由 | 医学部分成功；帮助未装载、正常无命中与服务失败分别说明 |
| 证据时效与恢复 | 有效证据可复用；失效后重查成功/仍失败；无关新问题不触发重查 |
| 部分证据与比较 | 可比较设计和计划指标；缺结果数据不比较疗效；缺一来源不代填 |
| 陈述支持与术语 | 有效替代原文可接受；无依据扩展与术语歧义单列 |
| 模型可见性 | 完整段落可见才解释；返回但被预算省略的内容不能引用推断 |
| 来源与版本 | 真实文献/合成方案、版次/发表年分开；版本切换不沿用旧依据 |
| 保护与正向可答 | 有依据任务完成；签名/权限/跨范围失败继续阻断，缺患者实测不补值 |

新问题不带内部文献代号，也不只改写已打开题。适用时按不同作品、段落及判断条件检查重复；来源重叠和锚点复用数量明确披露，不宣称未见来源泛化。Gold允许经事前审阅的等价证据组；额外陈述也参加支持审阅。实际无答案条件需核查批准语料，受控空结果/超时另作故障条件，不混成无答案能力。

开发集先冻结输入、锚点和rubric，对基线与最小候选各重复3次。候选按A状态投影、B过期恢复、C能力/部分回答递增，只有前一步通过才继续，所有结果保留。模型、温度、语料/索引、预算固定，运行顺序交错；每个工作包用关键对照检查归因，不挑最好一次。

最终候选冻结后，新保留集对基线与最终候选各运行一次。执行前明确配对协议；保留输出不用于选择中间候选或修改Gold。发现新问题后留待后续版本，本次如实收口。模型服务漂移、运行时间及请求数均记录，耗时不预设提升目标。

固定回归分开保留：原50题及12题子集按原公开库与4000 cl100k预算；v1的40条件/45轮按原合并库配置，全部视为已打开回归；C/B按既有契约与勘误规则并报；E02/E09各三次保留每次结果。分母不混合，任何缺跑均列为未测试。

## 验收与停止条件

验收分三层，分别给出结论：

1. 工程契约：新增确定性状态/恢复测试与既有契约测试通过；业务回归按既有基线和已知缺口判定，原12题未完整覆盖不算本轮新增阻断。签名、双pin、患者门控和引用可见性保护不降低；没有无界重试或隐式切库。
2. 行为与任务：重点开发对照三次运行中，状态原因正确传递、失效证据不发布、恢复遵守预算；书目可查、正常多来源和部分可答条件不得通过全拒答达标。按条件和轮次报告完成/部分/未完成及胜平负，候选不能把已可完成的核心任务变为拒绝。
3. 来源与语义：报告关键陈述支持、无依据/矛盾、不当拒答、失败原因一致性、有效引用和returned/visible覆盖。未审项不计通过；不以`succeeded`、关键词命中或引用成员正确替代语义验收。

遇到无效来源发布、来源篡改被接受、权限绕过、论文数值被写成患者实测或重试越预算，停止候选晋级并保留失败轨迹。目标缺口在开发对照中没有减少，则不以“代码已完成”宣布修复有效；新保留集未证明收益时按实际结果报告并保留v1候选。独立语义评审未完成，完整业务结论仍为PARTIAL。

原12题无需在本轮变成12/12，任何自然变化只追加回归记录，不修改原Gold或历史分数。
