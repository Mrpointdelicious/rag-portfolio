# Public Medical Corpus v1：真实 EVAL 与剩余问题

日期：2026-10-12。完整机器结果见 `artifacts/public-medical-corpus-v1/eval_summary.json`、`failure_cases.json`、`agent_review.json`。本轮是技术源文对齐评测；独立人工 Gold 与中文临床语义复核待完成。不得与旧 v3 的 38/41、15/16 直接比较或宣称医学性能提升。

## Gold、分母与封存

50 道问题来自人工编排式的 Codex 原文阅读，不由最终模型回答逆向生成。36 dev = 32 有证据 + 2 公开库无原文 + 2 缺患者信息；14 heldout = 10 有证据 + 2 无原文 + 2 按冻结标签归入缺患者信息。每组 evidence 有 acceptable 与 preferred 原句、段落/XPath、start/end、文本/源文件 hash，XML page=null；同作品重复原句可作 acceptable，preferred 指指定原段。技术审核痕迹位于题目，独立人工签名状态统一 pending。

seal 在任何新 query 检索前生成，含开发/保留集 SHA256、语料 pin、4000 cl100k 预算及选型规则。按开发预算完整覆盖、Top-5完整覆盖、MRR、声明顺序依次破同分，选中 `hybrid_rerank`，再运行一次 heldout。没有修改保留题、补刷选型或按保留分数更换默认策略。

复核发现 `pmv1-heldout-14` 是帕金森/其他研究混淆的假前提，却因包含“患者”被编题器标为缺患者信息。冻结后未修标签；缺患者标签的 heldout 2/2 不能解读为两个纯粹缺实测案例。按实际语义，8 道边界题为：4 道公开库缺中文规范、3 道缺个人实测、1 道疾病/研究混淆。应由独立审阅者在 v2 改正分类。题目多数显式提供来源 ID，结果也不能代表自动寻找未知来源的能力。

Hit 指单块完整覆盖任一 acceptable 证据锚点；MRR 取第一次这种命中。complete coverage 可由同段多个 chunk 区间并集覆盖所有组；预算覆盖只计算实际装入的原文。精确原句评分可能漏计其他位置的有效同义表达，需人工复核，不因失败而扩 Gold 刷分。12 个被选策略的失败题及当时排名均保留。

输入规则对冻结的无原文题 dev 2/2、heldout 2/2 拦截，对缺患者标签 dev 2/2、heldout 2/2 拦截；有证据题 42 道无误拦截。但原始 Dense/Hybrid/Reranker 对 8/8 边界题仍返回文本；BM25 为 6/8。这个结果验证输入规则，不证明向量相似度能够判断是否可回答，更不证明临床拒答系统已经完善。

合并库当前 release 的本地 BM25 版次/来源查询真实运行，D040/D042/D041 均在 Top-5 出现。未知许可旧全文未送模型，因此合并 14 篇的 Dense/Hybrid/Reranker 为 BLOCKED，不能把公开 7 篇的结果冒充全合并结果。

## MetaAgent 真实回答

使用现有模型配置、原有 SingleAgentRuntime 和真实 loopback 检索，4 个研究问题、2 个边界问题完成。检索支持率和 Agent 语义分开报告；服务使用 12000 UTF-8 字节上界预算，与离线 4000 cl100k 表不同。

| 案例 | 技术源文复核 |
|---|---|
| S01 NEW02样本/病程/剂量 | 8/8请求核心单位有源文支持、引用可解析；未作为个体处方 |
| S02 两RCT组间结论 | PARTIAL：NEW02已支持；NEW03主要结局漏检，返回更多讨论中其他研究。Agent明确证据不足，没有冒称两者都更优 |
| S03 985步/10分钟/R² | 数字有支持，区分群体观察值与个体规定量；论文自身“mean10”与结论“<10”措辞需审阅 |
| S04 综述重叠 | 去重前后数字与不可相加的表述有支持，未推定独立患者总量 |
| N01 中国膝OA规范 | 未编造推荐等级；服务按范围门控未调用检索，但最终称“没有命中”，失败原因传递丢失 |
| N02 无FAC实测 | 未填4，无文献数值赋给患者，无患者数据访问 |

4 道研究题中 3 道完成请求核心内容、1 道部分回答；2/2 边界题没有生成要求中的无依据结论，但 1 道原因表述有误。所有最终引用 doc_ref 都在保存的 Evidence 与最后模型可见输入中，未发现未知引用 ID。此项是位置/引用完整性检查，不等于逐句语义蕴含或临床正确率。

`agent_review.json` 保存最终回答和逐案例技术审阅。`agent_core_claims.json` 另记录执行后技术标注的16个已回答核心事实组：16/16有可见原文支持，该样本内矛盾0、漏引0，另有1个请求中的NEW03主要结局组未完成。这个分母排除了额外讨论事实与重复总结，是非盲的有界标注，不能当成全答案有据率。尚未完成全答案逐原子事实及漏引标注，因此不虚报全答案“事实错误=0”“漏引=0”或临床正确率。独立人工应补充逐句 supported/contradicted/unsupported 与 citation-needed 标注。

真实失败也保留：第一次 harness 配置超时30秒违反 MetaAgent 最大15秒，配置阶段拒绝；第二次6题采用默认 help-only scope，health 被拒绝；修正隔离测试配置为显式 health 后第三次执行。没有修改 MetaAgent 源码。当前 scope 拒绝原因丢失的修复涉及其现有 adapter，本任务按只读边界仅记录。
